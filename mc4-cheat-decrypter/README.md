# MC4 Cheat Decrypter

A tool to decrypt MC4 cheat files

Also available as a web page, running entirely in your browser: **https://bucanero.github.io/save-decrypters/mc4-cheat-decrypter/web/**

```
USAGE: ./mc4-cheat-decrypter [option] filename

OPTIONS        Explanation:
 -d            Decrypt File
 -e            Encrypt File
```
