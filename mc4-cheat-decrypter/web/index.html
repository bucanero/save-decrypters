MC4 Cheat Decrypter

Decrypt an MC4 cheat file to its XML, edit it, then encrypt it back. Everything runs in this tab — your files are never uploaded.

    
  
    

  
    MC4 files are base64-encoded AES-256-CBC. Decrypting gives the cheat XML, padded with blank lines to a 16-byte boundary as in the original file.
    Command-line version: mc4-cheat-decrypter.
